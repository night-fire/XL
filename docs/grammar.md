# Грамматика и синтаксис языка XL

## Общие принципы

- Нет исключений из правил.
- Порядок слов свободный, смысл определяется маркерами ролей.
- Нет рода, числа, падежей, времён.

## Маркеры ролей

Каждое слово получает маркер, определяющий его функцию в предложении:
- **Действие** (глагол)
- **Объект** (существительное)
- **Качество** (прилагательное/наречие)
- **Связь** (служебные слова)

Маркеры — отдельные короткие морфемы, присоединяемые к словам.

## Пример структуры предложения

- [Объект] [Качество] [Действие] [Объект]
- Пример: "Я быстро читаю книгу" → "я-К ОБ-Д ч-Д к-О"

## Отрицание и вопрос

- Отрицание: специальная частица перед действием.
- Вопрос: специальная частица в начале предложения.

## Примеры

- Утверждение: "он ест хлеб" → "он-О есть-Д хлеб-О"
- Вопрос: "? он-О есть-Д хлеб-О"
- Отрицание: "он-О не есть-Д хлеб-О"
