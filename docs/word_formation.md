# Словообразование в языке XL

## Принципы

- Все слова строятся из морфем: корень + маркеры ролей + дополнительные элементы.
- Нет синонимов: для каждого понятия — только одно слово.
- Новые слова образуются по строгим правилам, понятным любому носителю.

## Типы морфем

- **Корень** — основное значение.
- **Ролевой маркер** — функция слова в предложении.
- **Модификаторы** — оттенки смысла, эмоции, степень, принадлежность и т.д.

## Примеры словообразования

- "человек" (корень) + "-О" (объект) = "человек-О"
- "большой" (корень) + "-К" (качество) = "большой-К"
- "бежать" (корень) + "-Д" (действие) = "бежать-Д"

## Создание новых слов

- Для новых понятий используется комбинация существующих корней и модификаторов.
- Нет заимствований из других языков.
- Все новые слова проходят стандартизацию сообществом носителей.

## Примеры

- "автомобиль" = "двигаться-Д" + "самостоятельно-М" + "наземно-М" = "двигаться-Д-сам-М-зем-М"
- "компьютер" = "считать-Д" + "электронно-М" + "устройство-О" = "считать-Д-эл-М-устр-О"
