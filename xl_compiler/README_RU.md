# Компилятор XL на Rust

Это прототип полноценного компилятора для языка **XL**, написанный на Rust. На текущий момент поддерживается лексический анализ, парсинг и отладочный вывод AST.

## Сборка

```
cargo build --release
```

## Запуск

```
cargo run -- examples/hello.xl
```

## Дальнейшие планы

* Анализ семантики (проверка типов, разрешение имён)
* Генерация LLVM IR и вывод исполняемых файлов
* Оптимизации
* Тестовый пакет и CI
