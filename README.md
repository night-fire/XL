# XL Compiler (xlc)

`xlc` — это компилятор, написанный на Rust для экспериментального языка **XL**.

## Возможности MVP

* Лексический анализ на базе [`logos`](https://crates.io/crates/logos)
* Рекурсивный нисходящий парсер
* AST и минимальная семантическая проверка
* Генерация исходного кода на Rust
* Запуск `rustc` для получения нативного исполняемого файла

На данный момент поддерживаются:

* Определения функций
* Параметры и возвращаемый тип `i32`
* Оператор `return`
* Арифметические выражения `+ - * /`

```xl
function main() -> i32 {
    return 1 + 2 * 3;
}
```

## Установка и запуск

```bash
# Требуется установленный Rust toolchain
cargo build --release
./target/release/xlc examples/hello.xl -o hello
```

## Планы развития

* Переменные `let` и блочная область видимости
* Условные операторы, циклы, сопоставление с образцом
* Статическая типизация с выводом типов
* Генерация LLVM IR вместо промежуточного Rust
* Поддержка модулей и пакетов
* Самокомпиляция: компилятор XL, написанный на XL
