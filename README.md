# XL Language & Compiler (`xlc`)

XL — экспериментальный язык программирования, предназначенный для разработки компиляторов.  
Он реализован «с нуля» в этом репозитории: полная цепочка *лексер → парсер → семантический анализ → генерация LLVM IR → линковка*.

## Быстрый старт

```bash
# Сборка компилятора
cargo build --release -p xlc

# Пример исходника (example.xl)
cat > example.xl <<'SRC'
fn main() -> Int {
    return 1 + 2 * 3;
}
SRC

# Компиляция в исполняемый файл
./target/release/xlc example.xl -o example

# Запуск
./example   # → 7

# Или вывод LLVM IR
./target/release/xlc --emit-ir example.xl -o example.ll
```

## Мини-спецификация XL v0.1

* Чувствителен к регистру
* Отладочное многословие отсутствует — язык строгий и лаконичный

### Типы

| Синтаксис | Описание |
|-----------|----------|
| `Int`     | 64-битовое знаковое целое число |
| `Bool`    | Логический тип |
| `String`  | UTF-8 строка |
| `Void`    | Отсутствие значения (по-умолчанию функции без `return`) |

### Объявления функций

```
fn <name>(<param>: <Type>, ...) -> <ReturnType> {
    // тело
}
```

Параметры пока не используются генератором кода, но резерв зарезервирован.

### Выражения

* Арифметические: `+ - * /` (приоритет * / > + -)
* Литералы: `123`, `"string"`, `true`, `false`
* Вызовы функций: `foo(1, 2)`

### Оператор `let`

```
let x: Int = 42;
```

Аннотация типа может быть опущена: `let x = 42;`

### Возврат значения

`return <expr>;`

## Архитектура компилятора

```
src/
  token.rs   — определение токенов (статический лексическая грамматика на Logos)
  lexer.rs   — лексический анализ
  parser.rs  — рекурсивно-нисходящий парсер → AST
  ast.rs     — структуры AST
  semantic.rs— проверка типов (упрощённая)
  codegen.rs — генерация LLVM IR (inkwell)
  main.rs    — CLI (clap)
```
